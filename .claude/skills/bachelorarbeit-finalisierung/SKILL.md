# bachelorarbeit-finalisierung

**Trigger:** „Mach die Arbeit fertig" / „Word-Datei" / „Abgabeversion" / „Finale Version"

## Beschreibung
Gesamtcheck (roter Faden, Begriffskonsistenz, Übergänge), Literaturverzeichnis aus Kapitel-Quellenlisten, Word-Formatierung nach Hochschulvorgaben.

**Input:** Alle reviewten/überarbeiteten Kapitel + Formatvorgaben + Titelblatt-Infos  
**Output:** `06-final/bachelorarbeit_final.docx`, `02-quellen/Literaturverzeichnis_final.md`, Prüfbericht

---

## Ablauf

1. Gesamttext-Prüfung
   - Roter Faden: Kapitel folgen Forschungsfrage?
   - Übergänge: Logisch + elegant?
   - Begriffe: Konsistent definiert + verwendet?
   - Wiederholungen: Nötig oder redundant?

2. Literaturverzeichnis erstellen
   - Alle Quellen aus Kapitel-Tabellen sammeln
   - Duplikate entfernen
   - Harvard-Stil anwenden (alphabetisch)
   - Datei: `02-quellen/Literaturverzeichnis_final.md`

3. Word-Datei generieren
   - Titel + Inhaltsverzeichnis-Template
   - Alle Kapitel-Texte einfügen (v1 oder v2)
   - Zitate konsistent formatiert
   - Fußnoten (falls vorhanden) → Endnoten
   - Abbildungsverzeichnis (aus Platzhaltern)
   - Literaturverzeichnis anhängen
   - Pfad: `06-final/bachelorarbeit_final.docx`

4. Formatierung
   - Überschriften-Hierarchie
   - Seitenumbrüche vor Kapiteln
   - Schriftart, Größe, Zeilenabstand (Vorgaben)
   - Ränder (Standard: 2,5–3 cm)

5. Checkliste
   - Alle `[QUELLE ERGÄNZEN]` + `[SEITE PRÜFEN]` geschlossen?
   - Alle `[ABBILDUNG X.Y]` durch Bilder ersetzt?
   - Seitenzahlen korrekt?
   - Inhaltsverzeichnis aktuell?

6. Prüfbericht schreiben
   - Was wurde geprüft?
   - Verbleibende offene Items?
   - Abgabe-Readiness-Status
