# bachelorarbeit-planung

**Trigger:** „Ich will eine Arbeit schreiben" / „Wo fange ich an?" / „Hilf mir bei der Forschungsfrage" / „Gliederung" / „Zeitplan"

## Beschreibung
Fundament: Themenfindung, Forschungsfrage, Gliederung mit Seitenzahlen, Ordnerstruktur, Zeitplanung. Berührt **keine Quellen** (Phase 2).

**Input:** Thema (oder nichts)  
**Output:** `02-quellen/Forschungsfrage.md`, `01-docs/Gliederung.md`, `03-text/XX-*/`-Ordner, `04-fortschritt/Fortschritt.md`

---

## Ablauf

1. Themenfindung (falls nötig)
   - Dialog mit Benutzer: Welches Thema interessiert?
   - Eingrenzen auf 3–5 mögliche Forschungsfragen

2. Forschungsfrage präzisieren
   - Konkret, beantwortbar, wissenschaftlich relevant
   - Datei: `02-quellen/Forschungsfrage.md`

3. Gliederung entwickeln
   - Struktur: Einleitung, Theorie, Ergebnisse/Diskussion, Fazit
   - Mit **Seitenzahlen** (z.B. Einleitung 3–5 Seiten)
   - Datei: `01-docs/Gliederung.md`

4. Kapitel-Ordner anlegen
   - `03-text/01-Einleitung/`, `03-text/02-Theorie/` usw.
   - Struktur in Fortschritt.md spiegeln

5. Zeitplan erstellen
   - Abgabedatum → Meilensteine (Recherche, Schreiben, Review)
   - In Fortschritt.md als Tabelle

6. Fortschritt.md initialisieren
   - Kapitel-Tabelle mit Status "Ausstehend"
   - Zeitplan-Spalten (Soll/Ist)
